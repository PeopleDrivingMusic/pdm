# Track / Release Context

A track is **not** only an audio file. In PDM a track/release can carry rich
context that deepens the fan relationship:

- story / description;
- lyrics notes;
- attached post;
- backstage video;
- gallery;
- poll;
- comments;
- support call-to-action;
- merch / ticket association;
- future revenue / funding participation ([[revenue-share-crowdfunding]]).

This is why content references catalog entities rather than duplicating them
(a [[post]] attaches a [[track]]/[[album]] via music attachments). It makes each
release a small hub inside the [[artist-page]] and feeds [[track-release-context]]
into recommendations and analytics. Contrast the thin audio-file model of generic
streaming ([[positioning]]).
