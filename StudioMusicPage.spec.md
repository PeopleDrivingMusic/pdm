# Artist Music Studio MVP — Spec

## Цель
Сделать MVP студии артиста: загрузка треков, управление альбомами, отображение каталога.

## Обязательный функционал
1. Отображение треков и альбомов.
2. Создание альбома (обложка, описание, название, дата релиза, жанры).
3. Создание трека (upload аудио, название, обложка, длительность, жанры).
4. Менеджмент треков и альбомов (редактирование, удаление).
5. Добавление/удаление треков из альбомов.

## UI/UX и компонентный подход
- Использовать SCSS переменные и темы из src/styles/themes.
- Использовать готовые компоненты из src/lib/ui.
- Если не хватает базовых контролов — сделать реюзабельными и вынести в src/lib/ui.
- Любые комплексные компоненты (например, uploader) — вынести в src/lib/ui.
- Страница строится через компонент StudioMusicPage, который лежит рядом с +page.svelte.
- В +page.svelte только импорт и рендер StudioMusicPage.
- Иерархия: простые контролы → общие компоненты (cards/tables/metrics) → компоновка в page.

## Страницы и состав UI
- Studio music page:
  - Сетка альбомов (обложка, название, дата релиза, статус).
  - Таблица/лист треков (название, длительность, метрики play/like/save, статус).
  - Модалки/формы: создать/редактировать альбом, создать/редактировать трек.
  - Управление связью треков и альбомов.

## Технические требования
- Данные хранятся в Postgres через Drizzle.
- CRUD для альбомов и треков через SvelteKit endpoints.
- Можно использовать form actions, но не обязательно; допускается работа напрямую через +server.ts endpoints.
- Для чтения данных использовать server load.

## Хранилище файлов (локально)
Используем локальную структуру (минимум для MVP):

static/uploads/
  audio/
    {artistId}/
      {trackId}/source.{ext}
  covers/
    albums/{artistId}/{albumId}.{ext}
    tracks/{artistId}/{trackId}.{ext}

- В БД хранится относительный путь к файлу.
- Валидация типов: аудио только mp3/wav, обложки jpg/png/webp.

## База данных
- Использовать существующие таблицы: albums, tracks, track_stats.
- Если нужно добавить поля или таблицы (например, storageKey, fileSize, mimeType) — добавить миграции и обновить schema.ts.

## Готовность (acceptance)
- CRUD альбомов и треков работает end‑to‑end.
- Добавление/удаление треков из альбомов работает.
- Studio страница отображает данные из БД.
- Все новые компоненты вынесены в src/lib/ui и экспортированы из index.ts.
- Стили соответствуют темам из src/styles/themes.
